How it works
  1. Hashing. Each city block hashes (seed, x, z) into height, tiers and facade. Same inputs, same building, every time.
  2. Chunks. 400 m squares are grown ahead of you and thrown away behind you, so the streets never end.
  3. Shader windows. No window is geometry. The GPU slices each wall into floors and rooms and decides which lights are on. Neon sign lettering is drawn the same way.
  4. Math traffic. A car is a lane, a speed and an offset. Its position is computed on the GPU from the clock each frame.
